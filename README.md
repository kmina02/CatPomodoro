# 냥모도로

시계에 매달린 고양이가 항상 화면 위에 떠 있는 macOS용 45/15 뽀모도로 타이머입니다.

## 기능

- 45분 집중 / 15분 휴식 기본 프리셋
- 25/5, 45/15, 60/15 빠른 프리셋과 직접 시간 조절
- 일시정지, 재개, 초기화
- 집중 및 휴식 종료 말풍선과 macOS 알림
- 집중 시간 75%, 50%, 25%, 10% 지점의 무작위 고양이 응원 말풍선
- 토마토 뒤의 연결부를 축으로 천천히 좌우로 흔들리는 고양이 꼬리
- 모든 데스크톱과 전체 화면 공간에 나타나는 투명 플로팅 패널
- 초기 디자인 대비 60% 크기의 컴팩트한 고양이 타이머
- 드래그 위치 저장
- 메뉴 막대에서 보기, 재생, 설정, 초기화, 종료

## 빌드 및 실행

macOS 13 이상과 Swift 5.9 이상이 필요합니다.

```bash
./Scripts/build_app.sh
open dist/CatPomodoro.app
```

처음 타이머가 완료될 때 알림 권한을 요청할 수 있습니다. 플로팅 패널의 `×`는 앱을 종료하지 않고 숨깁니다. 앱을 다시 더블클릭하거나 메뉴 막대의 타이머 아이콘을 누르면 패널이 다시 나타납니다.

완료 화면만 빠르게 확인하려면 개발용 실행 옵션을 사용할 수 있습니다.

```bash
open -n dist/CatPomodoro.app --args --preview-completion
```
